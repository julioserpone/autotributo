## Preguntas y bugs

- **Bug reproducible:** usa el template `Bug report`.
- **Mejora o funcionalidad:** usa el template `Feature request`.
- **Pregunta de uso:** abre una discusión o un issue con contexto; no uses el canal de seguridad.

Incluye siempre:

- Versión o commit.
- Entorno (local, staging, producción).
- Pasos de reproducción.
- Resultado esperado y real.
- Logs o capturas sin secretos, XML reales ni PII.
